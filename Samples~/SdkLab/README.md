# SDK Lab sample

Attach SdkLab to a GameObject in a scene, or open the complete ExampleProject in this repository. The full example adds scene switching and native build settings. The UI uses INuxieClient and shows real Feature snapshots, queries, explicit consumption IDs, App Actions and restore results. Editor simulation is opt-in and labelled.

See [example instructions](https://github.com/nuxieai/nuxie-unity/tree/main/ExampleProject). Sample scripts are canonical; `scripts/sync-example.py` updates the complete project's imported copy.
